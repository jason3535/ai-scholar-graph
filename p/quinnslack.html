Co-founded Sourcegraph in 2013 with Beyang Liu and ran it as CEO for twelve years: universal code search used across large codebases, later the Cody AI assistant, with more than $200M raised and a $2.6B valuation. Launched the agentic coding tool Amp in May 2025, and in Dec 2025 spun it out as Amp Frontier Corporation — an independent research lab pursuing frontier coding agents — with Slack as CEO and Dan Adler taking over Sourcegraph. Known for contrarian engineering positions: Amp stopped using GitHub-centric workflows, dropped mandatory code review and runs remote-first agent execution. Stanford CS.
